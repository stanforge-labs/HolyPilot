# Быстрый чеклист HolyPilot

## Пользователь

1. Откройте выданный оператором адрес HolyPilot и войдите в свою учётную запись.
2. Выберите нужное рабочее пространство.
3. Подключите платформу через OAuth в разделе «Подключения».
4. Выберите только те рекламные аккаунты, к которым нужен доступ.
5. Проверьте статус подключения и диагностику.
6. Подключите совместимый AI-клиент через частный MCP endpoint и разрешите доступ к нужному рабочему пространству.
7. Выполните запрос на чтение, например «Покажи доступные рекламные аккаунты».

Изменения рекламных объектов выполняются только при наличии разрешённого профиля записи и отдельного подтверждения владельца. Запрос на чтение не подтверждает доступность записи.
