# Подключение к HolyPilot

HolyPilot работает как размещённый сервис. Пользователь входит в веб-кабинет, выбирает рабочее пространство, подключает рекламные платформы через OAuth и даёт доступ совместимому AI-клиенту через MCP. Устанавливать этот репозиторий на компьютер клиента не нужно.

## Для пользователя

1. Откройте адрес HolyPilot, предоставленный оператором, и войдите в свою учётную запись.
2. Выберите рабочее пространство, к которому у вас есть доступ.
3. В разделе «Подключения» подключите платформу и выберите разрешённые рекламные аккаунты.
4. В разделе MCP следуйте инструкции для вашего AI-клиента и авторизуйте доступ к нужному рабочему пространству.
5. Проверьте список доступных аккаунтов и выполните первый запрос на чтение.

Если клиент запрашивает разрешение на изменение рекламы, проверьте запрошенные права. Применение поддерживаемого изменения требует отдельного preview и подтверждения в браузере; доступность записи зависит от настроек конкретного окружения.

## Для разработчика

Локальный запуск v2 описан в [README](README.md#локальная-разработка) и [руководстве по разработке](docs/architecture/v2/LOCAL_DEVELOPMENT_RU.md). Настройки OAuth, базы данных и провайдеров задаются для конкретного окружения. Не переносите локальные учётные данные в production и не коммитьте `.env`, токены или ключи провайдеров.

Инструкции в [docs/beta](docs/beta) описывают исторический Python beta-runtime. Их нельзя использовать как актуальную инструкцию для v2 без сверки с текущим кодом и конфигурацией.
